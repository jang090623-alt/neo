시작 전에 꼭

  1. 핀·너트는 인두로 데워서 넣습니다. 망치로 치면 구멍 바닥이 뚫려 핀이 짧아집니다. 바닥에 닿으면 멈추면 됩니다.
  2. 베어링은 바이스로 바깥 링을 고르게 눌러 넣습니다.
  3. 에폭시는 정해진 곳만: 입력 기어 6 · 허브 3 (축에) · 아이들러 축 · 고무 호스 (핀에) · 핑거·손잡이 (레버봉에) · 클러치 허브 (축에) · 강철 와셔 (허브에) · 크랭크 손잡이 축. 베어링·출력 기어·슬리브에는 묻히지 않습니다.
  4. 그리스는 톱니·허브·레일만 얇게 (PTFE). 베어링은 이미 그리스가 들어 있습니다.
  5. 클러치 조절나사는 M5×10을 끝까지. M5×12를 와셔 없이 쓰지 않습니다 (기어가 버티는 힘을 넘음).
  6. 덮개 없이 씁니다. 모터가 돌 때 클러치·스프로킷·기어에 손을 넣지 않고, 비상정지 버튼을 손 닿는 곳에 둡니다.
  7. 입력축은 435mm 그대로 씁니다. 끝판 A 바깥으로 102mm가 클러치·모터 연결 자리입니다.

홀센서 A3144 7개 (글자가 보이는 면에서 왼쪽부터)
① VCC → 5V   ② GND → GND   ③ OUT → 위 표의 핀
저항은 필요 없습니다 (펌웨어가 내부 풀업을 켬).

자석: 러그 3개(밑면), 표시 바퀴 4개(테). 센서 평면과 자석 사이 약 2.5mm.

전선: 센서·가변저항은 점퍼 케이블, 5V·GND는 만능기판에서 모아 나눔.

핀 번호는 펌웨어 build/src/fw/shifter_controller/shifter_controller.ino 그대로입니다 (GEAR_PIN = 4, 5, 6, 8, 9, 10).

펌웨어 올리기 · 시운전

  1. 컴퓨터에 Arduino IDE를 설치합니다.
  2. 라이브러리 "Joystick" (Matthew Heironimus)를 설치합니다. 라이브러리 관리에 없으면 GitHub ArduinoJoystickLibrary ZIP으로 설치합니다 (검색 결과는 미확인).
  3. 압축 파일의 shifter_controller.ino를 열고, 보드 = Arduino Leonardo, 포트를 고른 뒤 업로드합니다.
  4. 릴레이 모듈이 IN=HIGH일 때 켜지는 제품이면 파일 위쪽 RELAY_ACTIVE_LOW 를 false 로 바꿔 다시 올립니다.
시험합격
1켜기가속 페달을 뗀 채 전원 → 0.5초 뒤 릴레이 딸깍 (모터 허가)
2센서레버를 각 단에 넣고 시리얼 모니터/게임 컨트롤러 화면에서 그 단 버튼 1개만 켜지는지
3클러치 미끄럼모터 달기 전: 입력축 B 끝 칼라를 플라이어로 잡고, 앞판 둘레(반지름 50)에 끈 → 2L 생수병에 물. 0.82~1.53kg에서 미끄러지면 정상 (0.40~0.75 N·m)
4비상정지주행 중 3번 누름 → 바로 멈춤, 풀어도 가속 페달을 뗄 때까지 안 돎
5막힘 차단바퀴 덮개 센서 선을 뽑고 1단·클러치 뗌·페달 50% → 5초 안에 모터 차단, 페달 1초 떼면 다시 허가
6변속클러치 밟고 1→5단, 다운시프트, 건너뛰기 100번 → 핀·포켓 파손 없음

도는 부품을 손으로 막는 시험은 하지 않습니다. 시험 내용은 설계서 8장에서 덮개 관련만 뺀 것입니다.

문제 해결

증상원인해결
레버가 단에 안 들어감핀과 슬리브 포켓 위치가 안 맞음페달을 밟은 채 크랭크를 아주 살짝 돌림
달리다 변속이 저절로 빠짐핀이 짧음 (걸리는 길이 = 나온 길이 − 1)그 기어 핀을 인두로 데워 6mm까지 빼거나, 그 기어만 다시 출력
중립인데 기어가 긁히거나 같이 돎핀이 7mm보다 김 → 슬리브에 닿음핀 나온 길이를 재서 7mm 넘는 핀을 줄로 갈기
모터는 도는데 입력축이 안 돎클러치 페달을 안 밟았는데 케이블이 당겨져 있음 / 허브 에폭시가 안 붙음페달을 뗀 상태로 케이블을 다시 맞춤 (팽팽하되 포크를 당기지 않게)
페달을 밟아도 클러치가 안 끊김케이블이 느슨함페달을 뗀 채 속선을 당겨 M3×10 다시 조임
클러치가 너무 쉽게 미끄러짐설정 미끄럼 토크 약 0.58 N·m시운전 3번으로 재기. 0.40 N·m보다 작으면 M5×12 + M5 와셔(0.5) 1장 (설계서 8장 시험 3)
모터가 5초마다 멈춤출력축 rpm 펄스가 안 들어옴바퀴 자석·센서 틈(2.5mm)과 D7 배선 확인
전원을 켜도 모터 허가가 안 됨가속 페달을 밟은 채 켬 / 비상정지 눌림 / A4 배선페달을 떼고 0.5초 기다림, 비상정지 풀기
기어가 뻑뻑함축 끝 칼라가 끝판을 꽉 누름 / 그리스 없음칼라를 풀고 0.2mm쯤 틈을 둔 채 다시 조임, 톱니에 PTFE 그리스
레일 칼라가 밀림M3 덜 조임슬릿이 닫힐 때까지 조임

완성 · 사용법

  1. 가속 페달을 뗀 채 전원을 켜고, 1단에서 클러치를 밟은 채 가속 페달을 살짝 → 클러치를 천천히 뗍니다.
  2. 변속: 페달을 끝까지 밟음 → 레버를 중립 → 원하는 단 → 페달을 천천히 뗌.
  3. 레버가 안 들어가면 클러치를 밟은 채 가속 페달을 아주 살짝 밟아 핀과 포켓을 맞춥니다.
  4. 후진(R)은 레버를 눌러야 들어갑니다 (잠금).
  5. 후진(R)은 멈춘 뒤에만 넣습니다.
  6. 클러치는 약 0.58 N·m에서 미끄러지게 설정되어 기어를 보호합니다.

덮개가 없으니 모터가 도는 동안 클러치·스프로킷·기어에 손을 넣지 않습니다.
