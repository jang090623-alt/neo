# 3D프린팅 5단+후진 수동변속기 설계서 v4.1

작성: 2026-10-19 · 기준: 설계서 v3 + 계산서 v4.1(`calc/calc_report.md`) · 프린터: Ultimaker 2+ (2.85mm PLA)
파일: `tx.py`(부품 생성) · `asm.py`(조립·간섭) · `calc/`(계산서·FEM) · `fw/`(펌웨어) · `export.py`(STL) · `slice.py`(출력 시간) · `bom.py`(구매목록)

## 0. 결론
- **모든 부품의 부하를 계산하고 맞췄습니다.** 핵심은 클러치입니다. 클러치가 0.44~0.75 N·m에서 미끄러지므로 기어·축·허브에 걸리는 힘의 위쪽 한계가 정해집니다. v3는 모터 기동 토크 2.6 N·m 기준이라 피로 안전율이 1보다 작았습니다.
- 실제로 생기는 하중의 최소 안전율은 아래와 같습니다 (전부 1 이상).

| 항목 | 최소 안전율 |
|---|---|
| 기어 이뿌리 정적 | 7.5 |
| 기어 이뿌리 피로, 클러치 최대 토크 1만 회 | 1.96 |
| 기어 이뿌리 계속 운전, 200만 회 | 2.56 |
| 변속 충격 (순서대로·건너뛰기) | 3.3 |
| 레버봉 | 2.1 |
| 포크, 막힘 1만 회 | 1.32 |
| 축 | 15.8 |
| 베어링 C0/P | 82 |

- **형상 검사 결과:**
  - 26개 상태에서 간섭 0. 7단 × 클러치 물림·끊김 + 막힘 6을 검사했고, 의도한 후진 잠금 접촉만 있습니다.
  - 레버 H 경로 1mm 간격에서 간섭 0.
  - 기어 이 사이 최소 0.188mm.
  - STL 66개 모두 닫힌 형상, 출력 공간 초과 0.
- **독립 검산:** 별도 계산으로 계산서 오류 6개를 찾아 고쳤습니다. 그 결과 기어 응력이 v4보다 약 1.7배 높게(안전한 쪽으로) 다시 계산됐습니다. 고친 뒤에도 실제 하중의 안전율은 모두 1 이상입니다.
- **출력:** 118개, 약 335시간, 4.03kg (PrusaSlicer 추정).
- **남은 위험 (미검증):** "5단으로 달리다 바로 R" 오조작에서는 고무 쿠션이 82% 눌려 선형 계산 범위를 벗어납니다. 그래서 허브 D면 안전율 1.8은 실제보다 낙관적일 수 있습니다. 시험(8장 6번)으로 확인하고, 허브(20_hub)는 여분을 출력해 둡니다.

## 3. 하중과 안전율 (계산서 요약)
- **기준 하중:** 클러치 최대 0.752 N·m. 이 값은 설정(M5×10)에서 마찰계수가 가장 클 때(μ0.5, 새 코르크)입니다.
- **필요 토크** 0.237 N·m: 끌림 0.10 가정 + 1단 0.3초 가속.
- **공칭 미끄럼 토크** 0.58 N·m (μ0.4). 필요 토크의 2.5배입니다.
- **허용 응력:**
  - 정적: 출력 PLA 인장강도 XY 45.5 MPa.
  - 피로: Ezeh & Susmel 설계 곡선(생존 95%, 200만 회 = 인장강도의 10%).

| 부위 | 경우 | 응력 / 힘 | 안전율 |
|---|---|---|---|
| 1단·후진 이뿌리 (가장 불리) | 클러치 최대, 1만 회 | 6.0 MPa (K_V 1.09, K_Fβ 3.35) | 정적 7.5 / 피로 1.96 |
| 이뿌리 | 계속 운전(끌림×1.25), 200만 회 | 1.8 MPa | 피로 2.56 |

## 4. 클러치 설정과 조정
| 조절나사 (끝까지 조임) | 스프링 길이 | 누르는 힘 | 미끄럼 토크 μ0.3 / 0.4 / 0.5 |
|---|---|---|---|
| M5×8 (약하게) | 29mm | 23.0N | 0.26 / 0.35 / 0.45 N·m |
| **M5×10 (설정)** | 27mm | 38.3N | 0.44 / 0.58 / 0.75 N·m |
| M5×12 (**금지**) | 25mm | 53.6N | 0.61 / 0.82 / 1.05 N·m (기어 설계 하중 초과) |

- 컵 깊이는 s = 13 − 나사 길이입니다. 스프링 길이는 24 + s입니다.
- 릴리스 누름 볼트는 M5×20입니다. 물린 상태에서 압력판과 1.0mm 떨어지고, 밟으면 압력판이 1.5mm 움직입니다. 릴리스 링은 2.5mm 움직이고, 그래도 뒷판과 1.0mm 남습니다.
- **페달:**
  - 발 힘은 약 6.7N입니다 (복귀 스프링 제외).
  - 행정은 약 20mm입니다.
  - 케이블 장력은 29N입니다.

## 7. 출력·조립 순서
1. **공차부터 맞춥니다.**
   - 시험편: 00(구멍), 01(허브-슬리브), 02(핀·6003, 부품 도착 후). 03 스프로킷 캡은 맞음 확인 끝.
   - 맞는 값을 알려 주면 공차 상수(`SHAFT_HOLE`, `D_HOLE`, `BRG_SEAT`, `PIN_HOLE` 등)를 바꿔 전체를 다시 만듭니다.
2. **핵심 시험체를 먼저 출력합니다.**
   - 부품: 끝판 A·B, 받침 4, 1단 쌍(17·49), 1-2 허브·슬리브·포크, 스페이서·칼라.
   - 손으로 돌리며 변속 100회. 핀·포켓 파손 0이면 다음으로 넘어갑니다.
3. **기어 준비**
   - 출력 기어 6개 + 아이들러: 베어링 2개씩 압입.
   - 출력 기어 면에 Ø5×25 핀 4개씩 압입 (19mm 박힘, 6mm 나옴).
   - 나온 6mm에 NBR 호스 6mm를 에폭시로 붙입니다.
4. **슬리브:** 반쪽(포켓 바깥) + 링 + 반쪽. M3×20 3개를 꽂고, 머리와 너트가 육각 자리 안에 들어가게 합니다.
5. **끝판 A 준비**
   - 안쪽 면에서 6001 2개 압입.
   - 아이들러 축 55를 압입하고 에폭시로 고정.
   - 바깥면 포크 브래킷 자리 너트 홈에 M4 너트 4개.
6. **입력축 (A쪽부터):** 3 · R17 · 43 · 5단36 · 3 · 4단31 · 43 · 3단27 · 3 · 2단22 · 43 · 1단17 · 3
7. **출력축 (A쪽부터, 핀 방향 표시)**
   - 3 · R41(핀→B) · [1 · 허브+5-R 슬리브 · 1] · 5단30(핀→A) · 3
   - 4단35(핀→B) · [1 · 허브+3-4 · 1] · 3단39(핀→A) · 3
   - 2단44(핀→B) · [1 · 허브+1-2 · 1] · 1단49(핀→A) · 3
8. **아이들러:** 3 스페이서 · 기어 · 칼라
9. **끝판 B:** 베어링 2개를 끼웁니다. 축 양쪽 바깥에 9mm 스페이서 + 칼라를 답니다 (M3×12 자가탭, 너트 없음).
10. **변속 기구** (순서는 v3와 같음, 나사만 바뀜)
    1. 케이지는 M4×30 4개.
    2. 레일은 끝판 A → 칼라 → 카트리지(와셔·C252·와셔) → 칼라 → 끝판 B → 케이지 → 러그 순서로 끼웁니다.
    3. 카트리지 뚜껑은 M3×8 2개.
    4. 러그는 M3×30 2개(자가탭)로, 중립에서 세 러그 홈이 일직선이 되게 고정합니다.
    5. 디텐트: 볼 → C147 → M3×12. 레버·피벗(M4×30 8), 게이트(M4×30 4), 잠금 칼라(M3×12).
11. **클러치** (A쪽 입력축 끝, 모터 쪽으로 쌓음)
    1. 릴리스 링: 너트 홈에 M5 너트 3개, M5×20을 끝까지 조임. 보스에 6003, 6003 바깥에 캐리어.
    2. 뒷판: 끝판 쪽 면 홈에 M4 너트 3개. 모터 쪽 면에 코르크 링을 붙입니다.
    3. 디스크 허브(D)의 플랜지에 강철 와셔 DIN9021 M16을 에폭시로 붙입니다.
    4. 압력판: 코르크 링을 붙입니다.
    5. 기둥 3개와 스프링 C252 3개를 넣습니다.
    6. 앞판 준비: 6001 파일럿 베어링, 커플링 핀 Ø5×40 6개 압입, 둘레 홈에 M5 너트 3개, M5×10 끝까지 조임, 스프링 컵.
    7. M4×60 3개로 앞판·기둥·뒷판을 묶습니다.
    8. 끝 와셔(1mm) + 끝 칼라(8mm, M3×12)를 답니다.
    9. 포크 브래킷: 끝판 A 바깥면에 M4×16 4개. 포크 피벗은 M5×35 + 나일론 너트.

| 10 | 센서 | 각 단에서 홀센서, 표시 바퀴 rpm | 한 단에 센서 1개만 켜짐, rpm 이 이론값(1단 58 등)의 ±15% |
| 11 | 초보자 | 수동변속기를 모르는 학생 5명이 설명 없이 조작 | 실수·파손 기록 → 보강 |

- 도는 부품을 손으로 막는 시험은 하지 않습니다. 9번 시험은 센서 선을 뽑는 방식이라 실제로 막지 않아도 됩니다.

## 9. 전기·펌웨어
- **모터 전원:** 12V 배터리(+) → 15A 퓨즈(배터리 옆) → 40A 릴레이 접점 → 키트 모터 드라이버 → 모터. 전선은 1.5mm² 이상입니다.
- **릴레이 코일 회로:** 12V → 비상정지(b접점) → 덮개 스위치(C–NO) → [감지점] → 5V 릴레이 모듈 접점(NO) → 40A 릴레이 코일 → GND.
  - 코일에는 1N4007을 역방향으로 병렬로 답니다.
  - 감지점 12V를 10kΩ/4.7kΩ으로 나눠 아두이노 A4에 연결합니다 (약 3.8V).
- **펌웨어** `fw/shifter_controller/shifter_controller.ino` (레오나르도, 컴파일 확인 11,062바이트)
  1. 켤 때 가속 페달을 0.5초 떼고 있어야 모터를 허가합니다.
  2. 기어가 들어가 있고, 클러치를 뗐고, 페달이 30% 이상인데 출력축 펄스가 5초 동안 없으면 차단합니다. 페달을 1초 떼면 다시 허가합니다.
  3. 비상정지를 누르거나 덮개를 열면 대기 상태로 돌아갑니다. 풀거나 닫아도 페달을 뗀 상태가 이어져야 재허가합니다.
  4. 릴레이 모듈이 하이 트리거면 `RELAY_ACTIVE_LOW=false`로 바꿉니다.
- 게임 연동 축·버튼은 v3와 같습니다.

## 11. 클러치 인터록(클러치를 밟아야 레버가 움직이는 잠금)을 넣지 않은 이유
- 실제 차에는 없는 장치입니다. "현실과 똑같이 조작"하는 것이 목표입니다.
- 막으려던 위험이 이미 다른 장치로 제한됩니다.
  - 클러치를 안 밟고 변속해도 모터 쪽 토크는 클러치가 0.75 N·m에서 끊습니다. 그래서 충격 에너지는 클러치를 밟았을 때와 거의 같습니다 (계산서 6).
  - 레버를 세게 밀어도 포크 힘은 카트리지 스프링이 39N 이하로 제한합니다 (계산서 9).
- 케이블·잠금 핀이 늘어나면 고장 지점과 조정할 곳이 늘어납니다.
