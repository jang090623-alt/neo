작성: 2026-10-19 (v4.2 핸들 받침·기성 스프링·톱니 가변저항: 2026-10-22) · 기준: 설계서 v3 + 계산서 v4.1(`calc/calc_report.md`) · 프린터: Ultimaker 2+ (2.85mm PLA)
파일: `tx.py`(부품 생성) · `asm.py`(조립·간섭) · `calc/`(계산서·FEM) · `fw/`(펌웨어) · `export.py`(STL) · `slice.py`(출력 시간) · `bom.py`(구매목록)

## 0. 결론
- **모든 부품의 부하를 계산하고 맞췄습니다.** 핵심은 클러치입니다. 클러치가 0.44~0.75 N·m(스프링 하중 허용차 +10% 까지 0.83)에서 미끄러지므로 기어·축·허브에 걸리는 힘의 위쪽 한계가 정해집니다. v3는 모터 기동 토크 2.6 N·m 기준이라 피로 안전율이 1보다 작았습니다.
- 실제로 생기는 하중의 최소 안전율은 아래와 같습니다 (전부 1 이상, 스프링 하중 +10% 포함).

| 항목 | 최소 안전율 |
|---|---|
| 기어 이뿌리 정적 | 7.0 |
| 기어 이뿌리 피로, 클러치 최대 토크 1만 회 | 1.83 |
| 기어 이뿌리 계속 운전, 200만 회 | 2.56 |
| 변속 충격 (순서대로·건너뛰기) | 3.3 |
| 레버봉 | 2.1 |
| 포크, 막힘 1만 회 | 1.27 |
| 축 | 14.3 |
| 베어링 C0/P | 74 |

- **형상 검사 결과:**
  - 26개 상태에서 간섭 0. 7단 × 클러치 물림·끊김 + 막힘 6을 검사했고, 의도한 후진 잠금 접촉만 있습니다.
  - 레버 H 경로 1mm 간격에서 간섭 0.
  - 기어 이 사이 최소 0.188mm.
  - STL 74개 모두 닫힌 형상, 출력 공간 초과 0.
  - 핸들 받침: ±134° 까지 간섭 0, ±135° 에서 멈춤, 캠-롤러 틈 0 (`verify.py` 의 `steer`).
- **독립 검산:** 별도 계산으로 계산서 오류 6개를 찾아 고쳤습니다. 그 결과 기어 응력이 v4보다 약 1.7배 높게(안전한 쪽으로) 다시 계산됐습니다. 고친 뒤에도 실제 하중의 안전율은 모두 1 이상입니다.
- **출력:** 135개, 약 388시간, 4.70kg (PrusaSlicer 추정, v4.2 핸들 받침 8개 48시간 포함).
- **v4.2 (2026-10-22):** 사용자의 핸들에 축이 없어 핸들 받침을 새로 설계했습니다 (4-2). 축 D컷은 직접 만듭니다 (7장 0번).
  - 스프링은 판매 중인 기성품(스프링팜 SUS304 선경 1.5 · 외경 18 · 자유장 25, k ≈ 2.8)으로 정했습니다. 스프링 상수 하나(`SPRING_L0`·`SPRING_K`)에서 카트리지·클러치 컵·레버 스페이서·페달·핸들 길이를 다시 계산했고, 전단응력은 모두 인장강도의 35% 이하입니다 (계산서 13장).
  - 가변저항은 D축 국내품이 없어 톱니 축이고, 페달 팔·핸들 캠 구멍을 압입 구멍으로 바꿨습니다.
- **남은 위험 (미검증):** "5단으로 달리다 바로 R" 오조작에서는 고무 쿠션이 82% 눌려 선형 계산 범위를 벗어납니다. 그래서 허브 D면 안전율 1.8은 실제보다 낙관적일 수 있습니다. 시험(8장 6번)으로 확인하고, 허브(20_hub)는 여분을 출력해 둡니다.

### 4-1. 페달 (v4.1 2차, 클러치·브레이크 같은 부품)
- 운전자는 페달 받침의 −z 쪽에 앉습니다. 팔은 수직에서 앞(+z)으로 25° 기울어 쉬고, 밟으면 10.7° 더 기울어 끝 멈춤에 닿습니다.
- 피벗: 왼쪽 볼에서 M6×25 → 팔 왼쪽 면 홈의 M6 나일론 너트. 머리가 볼에 닿을 때까지만 조입니다 (볼트가 팔과 같이 돌아 풀리지 않음).
- 가변저항: 축(톱니, 15mm)을 팔의 압입 구멍(Ø5.85, 깊이 5)에 4mm 밀어 넣고, 몸통을 오른쪽 볼 바깥면 자리(Ø17.5 깊이 2.5)에 에폭시로 붙입니다. 굳기 전에 페달을 뗀 상태에서 몸통을 돌려 저항이 한쪽 끝 근처가 되게 맞춥니다.
- 케이블(클러치만): 속선을 팔 앞면 쪽에서 b=30 구멍(Ø3.4)에 넣어 니플이 앞면에 걸리게 하고, 운전자 쪽 받침(아우터 자리 Ø5.6)으로 보냅니다.
- 복귀 스프링 (기성품): 팔 앞면 자리(Ø20 깊이 1.5)와 받침 보스(Ø12) 사이. 쉴 때 22.3mm, 끝까지 밟으면 14.5mm.
- 받침은 남는 MDF 450×300 에 목재나사 4×16 4개씩 고정합니다. 검사는 `verify.py` 의 `pedal` 항목 (간섭 0, 끝 ±1° 에서만 멈춤에 닿음).

### 4-2. 핸들 받침 (v4.2, 부품 90~96, 검사 `verify.py` 의 `steer`)
- **구조:** 강철 축 Ø12 (마봉 봉 2 에서 106mm) 를 몸체(90)의 6001 두 개(간격 56)가 받칩니다. 앞에 허브(92)를 M3 무두볼트로 고정하고 핸들을 M5 6개로 붙입니다. 뒤에는 복귀 캠(93)과 가변저항이 있습니다.
- **회전 범위:** 좌우 135° (총 270°) 입니다.
  - 허브 뒷면의 멈춤턱이 몸체 앞면 홈의 막힌 부분(아래 60°)에 닿습니다. 핸들을 세게 돌려도 힘이 축을 거치지 않고 허브에서 몸체로 바로 갑니다.
  - 홈은 허브(Ø100)가 덮고 틈은 2mm 라 손가락이 들어가지 않습니다.
- **가운데 복귀:** 하트 모양 캠을 롤러(6001)가 아래에서 받치고, 롤러 요크(94)를 스프링 2개가 밀어 올립니다.
  - 135° 돌리면 롤러가 10mm 내려가고 스프링이 21.7 → 11.7mm 로 눌립니다. 가운데 힘(1개 9.3N)은 135° 에서 하중 +10% 의 전단응력이 허용(인장강도 35%)이 되게 정했습니다.
  - 복귀 토크는 가운데 0.08 N·m, 끝 0.32 N·m 입니다 (k 2.8 기준, `verify.py` 의 `steer`). 롤러라서 마찰로 가운데를 못 찾는 일이 없습니다.
- **가변저항:** 뒤 덮개(95)에 부싱으로 고정하고, 톱니 축이 캠 뒤의 압입 구멍(Ø5.85)에 7mm 들어갑니다. 270° 는 가변저항 회전 약 300° 안이라 양끝에 15° 씩 여유가 있습니다. 회전 방지 돌기는 잘라 내고, 몸통을 돌려 가운데를 맞춥니다.
- **설치:** 받침판(91, 200×100) 을 C클램프 2개로 책상 모서리에 고정합니다.
  - 받침판 앞 끝을 책상 모서리에 맞춥니다. 핸들 면은 모서리보다 37mm 앞이고, 축 높이는 책상 위 110mm 입니다.
  - Ø330 핸들이면 아래쪽이 책상 윗면보다 55mm 내려가지만, 모서리 앞이라 책상에 닿지 않습니다 (`wheel^table` 0).
- **가정 (사진 받은 뒤 확정):** 핸들 볼트는 6구멍 PCD 70, M5 로 가정했습니다 (`WHEEL_PCD`·`WHEEL_N`·`WHEEL_PHASE`). 다르면 허브(92)만 고칩니다.

## 9. 전기·펌웨어
- **모터 전원:** 12V 배터리(+) → 15A 퓨즈(배터리 옆) → 40A 릴레이 접점 → 키트 모터 드라이버 → 모터. 전선은 1.5mm² 이상입니다.
- **릴레이 코일 회로:** 12V → 비상정지(b접점) → 덮개 스위치(C–NO) → [감지점] → 5V 릴레이 모듈 접점(NO) → 40A 릴레이 코일 → GND.
  - 코일에는 1N4007을 역방향으로 병렬로 답니다.
  - 감지점 12V를 10kΩ/4.7kΩ으로 나눠 아두이노 A4에 연결합니다 (약 3.8V).
- **펌웨어** `fw/shifter_controller/shifter_controller.ino` (레오나르도, 컴파일 확인 11,062바이트)
  1. 켤 때 가속 페달을 0.5초 떼고 있어야 모터를 허가합니다.
  2. 기어가 들어가 있고, 클러치를 뗐고, 페달이 30% 이상인데 출력축 펄스가 5초 동안 없으면 차단합니다. 페달을 1초 떼면 다시 허가합니다.
  3. 비상정지를 누르거나 덮개를 열면 대기 상태로 돌아갑니다. 풀거나 닫아도 페달을 뗀 상태가 이어져야 재허가합니다.
  4. 릴레이 모듈이 하이 트리거면 `RELAY_ACTIVE_LOW=false`로 바꿉니다.
- 게임 연동 축·버튼은 v3와 같습니다.

## 11. 클러치 인터록(클러치를 밟아야 레버가 움직이는 잠금)을 넣지 않은 이유
- 실제 차에는 없는 장치입니다. "현실과 똑같이 조작"하는 것이 목표입니다.
- 막으려던 위험이 이미 다른 장치로 제한됩니다.
  - 클러치를 안 밟고 변속해도 모터 쪽 토크는 클러치가 0.83 N·m 이하에서 끊습니다. 그래서 충격 에너지는 클러치를 밟았을 때와 거의 같습니다 (계산서 6).
  - 레버를 세게 밀어도 포크 힘은 카트리지 스프링이 43N 이하로 제한합니다 (계산서 9).
- 케이블·잠금 핀이 늘어나면 고장 지점과 조정할 곳이 늘어납니다.
