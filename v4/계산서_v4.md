# 계산서 v4 (자동 생성: calc/calc.py → calc/report.py)

단위: N, mm, MPa, N·m. **SF** = 안전율(허용 ÷ 실제). 정적 SF 는 출력 PLA 인장강도(XY 45.5 MPa, Z 33.1 MPa), 피로 SF 는 Ezeh & Susmel 설계 곡선(생존확률 95%: 200만 회 = 인장강도의 10%, k=5.5)과 비교했습니다.

## 0. 가정 (측정해서 바꿔야 할 값)

- 1500 (24V 정격 3000rpm 의 절반, 미측정) → 감속기 출력 167rpm, 충격 계산은 200rpm
- 입력축 기준 끌림 토크 0.10 N·m (미측정: 2단계 조립 후 걸이 저울로 측정, 0.15 이하이면 합격)
- FDM 출력 기어 이 방향(리드) 오차 50 μm 가정 (미측정) + 축 기울기 x 이 폭
- NBR 쇼어 70A (E≈5.5 MPa, Gent), 호스 안5 x 바깥10 (두께 2.5), 4개 중 2개가 받는다고 가정
- 러그 M3 자가탭 나사가 레일을 누르는 힘 300N/개 가정 (손으로 조인 값, 미측정)
- 토크상수 = 정격토크 / (정격전류 - 무부하전류 0.6A 가정)
- 감속기 효율 0.81 가정 (미확인)
