# 새 세션 시작 프롬프트 (이 내용을 그대로 첫 메시지에 붙여 넣고 transmission_v4.zip 첨부)

나는 고등학생 octane이고, 물리 동아리 전시용으로 Ultimaker 2+(2.85mm PLA)로 "실제 차와 똑같이 조작하는" 5단+후진 수동변속기를 만들고 있어.
모터는 GGM K9DP90N2(24V 90W)에 감속기 K9P9BH(1/9)가 붙어 있고, 12V 배터리 1개로 돌림. 키트의 모터 드라이버와 가속 페달은 그대로 씀.
설계는 v4.1까지 끝났고 첨부한 zip에 모든 파일이 있어.

## 처음에 할 일
1. zip을 작업 폴더에 풀고 `v4/설계서_v4.md` → `v4/계산서_v4.md` → `v4/README.txt` 순서로 읽어.
2. `v4/src` 안 스크립트의 고정 경로를 작업 폴더로 바꿔.
   - 바꿀 경로: `/home/claude/tx4`, `/home/claude/tx`, `/home/claude/구매목록.xlsx`
   - `calc/fem_tooth.py` 는 `gearcalc.py`를 import 함. `gearcalc.py`는 `src/calc/`에 있음.
3. 필요한 패키지를 설치하고 `export.py`와 `verify.py --sweep`를 돌려서 이전 결과와 같은지 확인해.
   - 패키지: manifold3d shapely numpy trimesh scipy triangle openpyxl fast_simplification, 그리고 PrusaSlicer(슬라이스용)
   - 이전 결과: STL 66개 모두 닫힘, 26개 상태 중 간섭은 'R(안 누름)'의 gate–lock_collar 하나(의도된 후진 잠금), 맞물림 최소 0.188mm.
   - 결과가 다르면 작업을 멈추고 나한테 알려줘.

## 내가 원하는 방식
- 한국어 존댓말. 결론부터 짧게.
- 직접 확인한 데이터로만 판단하고, 확인 못 한 것은 "미검증"으로 표시.
- 선택지를 나열하지 말고 가장 좋은 방법 하나를 추천.
- 내가 해야 할 일은 번호 매긴 단계로.
- 되돌릴 수 없는 일(주문, 삭제 등)은 실행 전에 확인.
- 코드는 YAGNI: 요청하지 않은 추상화 금지, 가장 단순한 해법.
- 목표는 "한 번에 완벽하게": 추측으로 정하지 말고, 필요한 측정을 먼저 요청할 것.
