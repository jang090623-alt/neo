# 쇼핑몰 확인 부탁 (물품계획서 {N}줄)

고등학교 물리 동아리 RPM 이 3D 프린팅 5단+후진 수동변속기(전시용)를 만듭니다. 학교 "창체 동아리 물품 구입 신청" 양식에 넣을 물품 {N}줄을 쇼핑몰 화면에서 직접 확인해 주세요. 원래 세션은 쇼핑몰 화면을 열 수 없어서 일부 가격·옵션이 검색 결과나 추정입니다. 아래 표가 지금 목록입니다.

## 꼭 지킬 것
1. 쇼핑몰은 **S2B(학교장터)·쿠팡·11번가·G마켓만** 씁니다. 디바이스마트·미스미·알리익스프레스 등 다른 곳은 안 됩니다.
2. **국내배송만** 고릅니다. 해외직구·구매대행·해외배송(발송 국가 표시, 통관부호 필요, 도착 1주 이상 등) 상품은 빼고 같은 조건의 국내 상품으로 바꿉니다.
3. 주문·결제·장바구니 담기는 하지 않습니다. 판매자 문의 글이 꼭 필요하면 문구만 써서 사용자에게 보여 주고, 허락을 받은 뒤에 올립니다. 로그인이 필요하면 사용자에게 부탁합니다.
4. 줄마다 상품을 **하나만** 고릅니다. 후보를 나열하지 말고, 가장 좋은 것 하나와 이유 한 줄을 적습니다.
5. 조건이 같으면 판매자 수를 줄여 배송비를 아낍니다. 예를 들어 공구는 한 판매자에게서 고르고, 볼트는 지금처럼 리우툴 한 판매자에게서 고릅니다.
6. 가격은 VAT·옵션가를 포함한 **1단위 값**입니다. 묶음 상품이면 단위(예: 10개 봉)를 적습니다.
7. 화면에서 직접 본 값만 적습니다. 못 본 것은 "미확인"이라고 씁니다.

## 줄마다 할 일 (표의 '상태' 칸)
- **이번 목표는 값을 낮추는 것입니다.** 같은 조건이면 배송비까지 더해 가장 싼 국내배송 상품을 고릅니다.
- **확인:** 2026-10-22 에 화면에서 고른 상품입니다. 판매 중인지, 옵션 이름·가격·배송비·국내배송이 표와 같은지 봅니다. 바뀐 값만 고칩니다.
  - **상품을 바꾸지 않습니다.** 설계(스프링 길이, 가변저항 구멍, 축 공차)가 이 상품들의 치수에 맞춰져 있습니다. 특히 스프링·가변저항·마봉·스텐 환봉은 그대로입니다.
  - 예외: 품절·해외배송으로 바뀐 경우와, 아래 '배송비 줄이기' 줄은 같은 규격의 국내 상품으로 바꿀 수 있습니다.
- **검색:** 고른 상품이지만 화면으로 확인하지 못했습니다. 판매 중인지, 국내배송인지, 가격·배송비를 봅니다. 해외배송이면 같은 조건의 국내 상품으로 바꿉니다.
- **찾기:** 값을 낮추려고 새로 고르는 줄입니다. '꼭 맞아야 할 것'을 모두 만족하는 국내배송 상품 중 가장 싼 것 하나를 고릅니다.
  - 로켓배송(19,800원 이상 무료)이나 이미 목록에 있는 판매자 상품이면 배송비가 늘지 않아 더 좋습니다.
  - 상한 가격 안에 없으면 가장 가까운 것을 고르고 비고에 이유를 적습니다.

## 고르는 기준
- **샤프트 칼라 (G마켓 4101441390):** 국내배송인지, 옵션 "SCC6 6-12-6" 의 가격을 봅니다. 화면이 열리지 않으면 "미확인"으로 두고 사용자에게 직접 열어 달라고 합니다.
- **베어링 6001ZZ 10개 묶음 · 6003ZZ (2026-10-20 화면, 국내배송 미확인):** 해외배송이면 국내 일반 상품으로 바꿉니다. 6001 과 6003 을 한 판매자에게서 살 수 있으면 그쪽을 고릅니다.
- **PLA 2.85mm 1kg:** 지름이 **2.85mm** 로 적힌 것만 고릅니다 (1.75mm·3.0mm 는 안 됨). 검정 2 · 주황 2 · 파랑 1 을 **같은 브랜드**로 고르고, 지름 허용차(±0.05 등)를 적습니다.
- **디지털 캘리퍼스:** 분해능 0.01mm, 150mm, 스텐 몸체. 플라스틱 몸체는 뺍니다.
- **탁상 바이스:** 주물, 조 폭 75mm 이상, 클램프로 책상에 고정하는 것.
- **같은 상품의 더 작은 묶음:** 마봉 Ø12 는 6개 중 4개가 D컷 실수 대비 여분이라, 같은 상품에 1m 3개 옵션이 있으면 그것으로 바꿉니다. 평행핀 Ø5×25 는 28개면 되므로 같은 상품에 50개 이하 옵션이 있으면 그것으로 바꿉니다.
- **배송비 줄이기:** 아래 줄은 배송비가 상품값보다 큽니다. 같은 규격을 로켓배송이나 이미 목록에 있는 판매자에게서 살 수 있으면 바꿉니다.
  - 평행핀 Ø5×40 (성일산업, 배송비 4,000): 평행핀 Ø5×25 판매자(링크베이, 무료배송)에 5×40 옵션이 있는지 봅니다. 공차 0~+0.01 이어야 합니다.
  - 코르크 시트 (효성문구 2,500) · 무두볼트 M3×8 (금성볼트 3,000) · 목재나사 4×16 (세종하우스 2,800) · 실리콘 전선 16AWG (넥스트코리아 3,000) · 자동차 릴레이 (오토월드 3,000) · 아두이노 레오나르도 (인투피온 2,700)
- **배송비:** 판매처마다 배송비와 무료배송 조건을 적고, 이 목록대로 샀을 때의 배송비 합계를 계산합니다.

## 돌려줄 결과 (사용자가 원래 세션에 그대로 붙여 넣습니다)
1. 아래 머리줄 그대로 된 **CSV 코드 블록 하나**를 출력합니다. {N}줄을 빠짐없이, no 순서대로 적습니다.
```
no,상태,상품URL,판매자,선택할 옵션(화면 그대로),단가,단위,배송비(판매처당),국내배송,꼭 맞아야 할 것 충족,비고
```
   - 상태: 그대로 / 가격변경 / 옵션변경 / 상품변경 / 못찾음
   - 상품URL은 짧은 주소로 적습니다: 쿠팡 `https://www.coupang.com/vp/products/번호`, 11번가 `https://www.11st.co.kr/products/번호`, G마켓 `https://item.gmarket.co.kr/Item?goodscode=번호`, S2B 상품 주소
   - 국내배송·꼭 맞아야 할 것 충족: 예 / 아니오 / 일부
   - 비고: 바꾼 이유, 스프링의 d·OD·L0·Nt·k, 가변저항 축 모양 등
2. CSV 다음에 "배송비 합계"와 "사용자에게 물어볼 것"을 짧게 적습니다.
3. 파일로 저장할 수 있으면 `쇼핑몰_확인결과.csv` 로도 저장합니다.
